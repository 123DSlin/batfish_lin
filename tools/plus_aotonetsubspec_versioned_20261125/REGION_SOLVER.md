# Restored full-native Plus region solver

For each released configuration line, all other configuration stays fixed.
The complete native equations recompute route attributes, Best Route and
forwarding. Candidate recovery is certified before property projection.

Bad is an exact union of projections at solver-chosen fault witnesses, closed
by an UNSAT uncovered-counterexample query. Reference existence and Support
explicitly traverse each at-most-k physical fault. Support is the intersection
of exact per-fault existence projections. Allowed = Domain AND Support AND
NOT Bad. Each projection has its own equivalence certificate.

The whole-line result is specialized with other fields at their original
values. MED uses all unsigned 32-bit values; prepend uses all nonnegative
integers in the AS-path-length abstraction; prefix syntax is coupled and
symbolic. Communities retain the original encoded-tag scope.

This restores the pre-scalability implementation for result comparison.
